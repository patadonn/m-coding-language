MCL — краткая документация

Краткое описание

MCL — упрощённый предметно-ориентированный язык с поддержкой переменных, функций, классов, корутин и специальных блоков действий. В проекте реализованы: Tokenizator (лексер), Parser (AST), CodeGen (генерация C#) и Executor (интерпретатор).

Синтаксис

- Объявление переменных:
  - переменная ИМЯ;
  - переменная A,B = 1, "str";

- Присвоение:
  - X = 5;

- Вызов функции / метода:
  - имя(арг1, арг2);

- Блок действий (action block):
  - $ действие1, действие2 #
  - Пример: переменная A = $пропуск#,5#;  (действия между $ и # образуют список)

- Условие if/else:
  - если (условие) $ ... # иначе $ ... #

- Определение метода:
  - метод имя(парам1,парам2) $ ... #

- Корутины и защищённые корутины:
  - корутина — ключевое слово перед именем метода: метод корутина имя() $ ... #
  - защищённая корутина (безопасная) — модификатор "защ" перед определением метода: защ корутина имя() $ ... #
	- защ выполняет функцию: метод запускается в отдельном защищённом потоке/таске и не блокирует основной поток.
	- Исключения внутри защищённых корутин перехватываются и логгируются, не ломая остальную программу.

- Задержка внутри корутины / метода:
  - задержка(секунды) — встроенная функция, которая при исполнении делает Thread.Sleep(секунды * 1000).

- Классы и наследование:
  - класс Имя наследует БазовыйКласс $ ... #
  - Члены класса — методы и переменные, объявленные внутри блока действий класса.

Встроенные функции

- отладить("текст") — печатает текст в консоль (для быстрой отладки).
- задержка(секунды) — при исполнении приостанавливает текущий поток на указанное количество секунд.

Примеры

1) Простая программа

переменная A = 10;
переменная B = "hello";
отладить(B);

2) Условие

переменная X = 5;
если (X == 5) $
  отладить("X равен 5");
#

3) Метод и вызов

метод sayHello() $
  отладить("Hello from method");
#

sayHello();

4) Защищённая корутина (пример безопасной корутины)

защ корутина backgroundTask() $
  задержка(2);
  отладить("background finished");
#

backgroundTask(); // не блокирует основной поток; ошибки внутри перехватываются

5) Класс с наследованием

класс A $
  метод hello() $
	отладить("A hello");
  #
#

класс B наследует A $
  метод hello() $
	отладить("B hello");
  #
#

Замечания для разработчиков

- Tokenizator.Токенизовать разбивает исходник на токены.
- Parser преобразует токены в AST (ProgramNode и узлы: VarDeclarationNode, AssignmentNode, IfNode, FunctionCallNode, MethodDeclarationNode, ClassDeclarationNode, ExpressionNode и т.д.).
- CodeGen.GenerateCSharp принимает AST и возвращает строку с эквивалентным C# кодом.
- Executor.Execute выполняет AST напрямую (интерпретатор).

Поведение защищённых корутин

- При выполнении метода, помеченного как защ (и опционально как корутина), Executor запускает тело метода в Task.Run с блоком try/catch.
- Исключения внутри защищённой корутины логгируются (в консоль через отладить) и не прерывают выполнение главного потока или других корутин.
- Защищённые корутины выполняются асинхронно: вызов метода возвращает управление немедленно.

Примечание по генерации кода

- Имена идентификаторов при генерации C# нормализуются (недопустимые символы заменяются на '_').
- Типизация в рантайме простая: числа парсятся как double, строки как string, списки действий как object[].
