# m-coding-language

(In development) (Project has been renamed from MESCL to MCL) "MESCL - M-Engine
Scripts Coding Language" (.mscl) "MCL - M Coding language" (.m)

Tokenizator (1 updates) v 0.0.1 Alpha

Parser (Not done)

CodeGenerator

We're creating new high-level SAFM (Simple Accessible Fast Multifunctional)
Coding language called "MCL" (M Coding language) based on C#.

Main feature is that you can write code FULLY IN RUSSIAN LANGUAGE! Template:

```
переменная А = 54;

если (А == 54) $

    отладить(Отлично!);

#
```

[PLANS]:

```
"After developing the main release version we gonna try to translate it on English!"

"Make Compiler using C# then remake it using C++ or Rust"

"Make Game Engine Based on MCL"

"Make Compiler using MCL"
```
